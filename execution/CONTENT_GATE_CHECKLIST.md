# Per-Chapter Content Gate

Before an entire chapter is merged as complete:

## Story
- [ ] Cold Open exists
- [ ] knowledge delta defined
- [ ] canon anchor reviewed
- [ ] player local agency visible
- [ ] aftermath exists

## RPG
- [ ] exploration
- [ ] major dialogue
- [ ] one system challenge
- [ ] XP/progression opportunities
- [ ] equipment/skill relevance
- [ ] optional content

## Human scale
- [ ] food/home/work/transport/family/media detail represented
- [ ] at least one non-elite NPC
- [ ] macro event has concrete personal consequence

## Science
- [ ] science content verified
- [ ] player manipulates or reasons, not only reads

## Technical
- [ ] refs validate
- [ ] quest recoverable
- [ ] autosave checkpoint
- [ ] E2E main route
- [ ] chapter pack unload tested

## Rights
- [ ] no copied long-form text
- [ ] assets rights metadata
