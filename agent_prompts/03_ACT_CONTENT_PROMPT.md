Implement one campaign Act only after the preceding Gate is complete.

Before any content:
1. Read Narrative Bible.
2. Read Timeline & Chapters for this Act.
3. Read Science & Philosophy Matrix.
4. Create an Act Beat Sheet and per-scene Scene Cards.
5. Identify Canon Anchors and protected outcomes.
6. Identify at least one cross-era callback.
7. Run content review before implementation.

Then implement chapter-by-chapter. For each chapter:
- validate content
- run chapter golden path
- verify save recovery
- record rights metadata for assets
- update traceability

Do not bulk-generate hundreds of dialogue nodes without scene-level review.
Quality of character scenes is more important than dialogue count.
